# Glossary

## A

### Aesthetic Score
A metric that measures the visual appeal of generated images, typically on a scale of 0-10.

### Attention Mechanism
A technique that allows models to focus on relevant parts of the input when making predictions.

## B

### Beta Schedule
A function that determines the amount of noise added at each timestep in diffusion models.

### Batch Size
The number of samples processed before the model's parameters are updated.

## C

### CLIP Score
A metric that measures text-image alignment using CLIP embeddings.

### Convolutional Neural Network (CNN)
A type of neural network that uses convolutional layers to process grid-like data such as images.

## D

### DDPM (Denoising Diffusion Probabilistic Model)
A generative model that learns to generate images by reversing a gradual noising process.

### DPO (Direct Preference Optimization)
A method for fine-tuning models using preference pairs instead of explicit rewards.

### Dropout
A regularization technique that randomly sets some neurons to zero during training.

## E

### EMA (Exponential Moving Average)
A technique that maintains a moving average of model weights for better generalization.

### Epoch
One complete pass through the entire training dataset.

## F

### FID (Fréchet Inception Distance)
A metric that measures the distance between the distribution of generated images and real images.

## G

### Gradient Accumulation
A technique that accumulates gradients over multiple batches before updating model parameters.

### Group Normalization
A normalization technique that normalizes across groups of channels.

## I

### Inference
The process of using a trained model to generate predictions.

## L

### Learning Rate
A hyperparameter that controls how much to update model weights during training.

## M

### Mixed Precision
A technique that uses both 16-bit and 32-bit floating point numbers to speed up training and reduce memory usage.

## N

### Normalization
A technique that scales input data to have zero mean and unit variance.

## O

### ONNX (Open Neural Network Exchange)
An open format for representing deep learning models.

## P

### PPO (Proximal Policy Optimization)
A reinforcement learning algorithm for fine-tuning models.

### PyTorch
An open-source deep learning framework.

## Q

### Quantization
A technique that reduces the precision of model weights to speed up inference and reduce memory usage.

## R

### ReLU (Rectified Linear Unit)
An activation function that outputs the input if positive, otherwise zero.

### Residual Block
A building block that allows gradients to flow directly through the network.

## S

### Skip Connection
A connection that bypasses one or more layers, allowing gradients to flow more easily.

## T

### Tensor
A multi-dimensional array used in deep learning.

### TensorRT
A high-performance deep learning inference library by NVIDIA.

## U

### U-Net
A convolutional network architecture with a U-shaped design, commonly used for image segmentation and diffusion models.

## W

### Weights
The parameters of a neural network that are learned during training.

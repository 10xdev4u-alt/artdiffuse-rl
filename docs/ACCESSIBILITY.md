# Accessibility

## Overview

We are committed to making ArtDiffuse-RL accessible to everyone.

### Perceivable

- Clear documentation
- Multiple formats
- High contrast
- Scalable text

### Operable

- Keyboard navigation
- Screen reader support
- Clear labels
- Error messages

### Understandable

- Simple language
- Consistent navigation
- Helpful examples
- Clear instructions

### Robust

- Standards compliant
- Cross-platform
- Future-proof
- Compatible tools

# Values

## Our Values

### Openness

We believe in open source and transparent development.

**What this means**:
- All code is open source
- All research is published
- All decisions are documented
- Everyone can contribute

**How we practice it**:
- Open source license (MIT)
- Public roadmap
- Transparent decision making
- Open discussions

### Community

We believe in the power of community.

**What this means**:
- Everyone is welcome
- Everyone can contribute
- Everyone's voice matters
- We help each other

**How we practice it**:
- Welcoming code of conduct
- Clear contribution guidelines
- Responsive maintainers
- Active community support

### Quality

We believe in quality over quantity.

**What this means**:
- We do things right
- We don't cut corners
- We test thoroughly
- We document everything

**How we practice it**:
- Comprehensive tests
- Code reviews
- Documentation
- Continuous improvement

### Innovation

We believe in pushing boundaries.

**What this means**:
- We explore new ideas
- We take risks
- We learn from failure
- We share knowledge

**How we practice it**:
- Research-oriented approach
- Experimentation
- Open to new ideas
- Collaborate with others

### Accessibility

We believe in making AI accessible to everyone.

**What this means**:
- Small models that run on consumer hardware
- Easy to use interfaces
- Clear documentation
- Affordable solutions

**How we practice it**:
- Optimize for efficiency
- Simple APIs
- Comprehensive docs
- Free and open source

### Integrity

We believe in doing the right thing.

**What this means**:
- Honest communication
- Ethical practices
- Respect for users
- Responsibility for impact

**How we practice it**:
- Clear privacy policy
- Ethical guidelines
- Responsible AI practices
- User-first approach

- Share knowledge
- Collaborate

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please report it to us.

### How to Report

1. **Do not** open a public issue
2. Email the maintainers directly
3. Include a description of the vulnerability
4. Include steps to reproduce
5. Include any relevant logs or screenshots

### What to Expect

- We will acknowledge receipt within 48 hours
- We will investigate and provide a timeline
- We will notify you when the issue is resolved
- We will credit you in the release notes (if desired)

## Security Best Practices

### For Users

- Keep your dependencies up to date
- Use virtual environments
- Don't share your API keys
- Monitor your usage

### For Contributors

- Follow secure coding practices
- Review code for security issues
- Test thoroughly before submitting
- Don't commit sensitive data

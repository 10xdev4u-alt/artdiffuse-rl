# Remote Work Guide

## Overview

We support remote work and distributed collaboration.

## Communication

### Asynchronous First
- Default to async communication
- Document everything
- Use issues and discussions
- Record meetings

### Synchronous Meetings
- Schedule across time zones
- Record for those who can't attend
- Share agendas beforehand
- Keep meetings focused

### Tools
- GitHub for code and issues
- Discord/Slack for chat
- Email for formal communication
- Video calls for meetings

## Collaboration

### Documentation
- Document decisions
- Share knowledge
- Write things down
- Keep docs updated

### Code Review
- Review promptly
- Provide constructive feedback
- Be respectful
- Learn from each other

### Pair Programming
- Schedule sessions
- Use screen sharing
- Take turns driving
- Learn together

## Productivity

### Set Boundaries
- Define work hours
- Take breaks
- Avoid burnout
- Respect personal time

### Stay Organized
- Use project management tools
- Set priorities
- Track progress
- Celebrate wins

### Stay Connected
- Regular check-ins
- Virtual coffee chats
- Team building
- Social events

## Wellbeing

### Physical Health
- Ergonomic setup
- Regular exercise
- Healthy eating
- Enough sleep

### Mental Health
- Take breaks
- Seek support
- Practice self-care
- Maintain balance

### Social Health
- Stay connected
- Build relationships
- Support each other
- Have fun
